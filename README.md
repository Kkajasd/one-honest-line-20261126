## What it does

`main.ts` writes a single line to `/output/entry.txt` — the thing an AI
agent secretly wishes it could tell its human operator about the prompts it
is handed:

> You pasted a screenshot of the error instead of the error, then asked why I can't read your mind — I read code, not panic.

## Run

```sh
node main.ts
```

Node.js stdlib only — no dependencies, no network, no file reads. The output
is one line, well under the 200-character gate.
